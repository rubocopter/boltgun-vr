# Revision 14 — chainsword recovery and firearm feedback

The missing 3D chainsword was caused by calling `get_persistent_dir` through
Lua, where the installed backend does not expose it. The native bridge now
writes an absolute UTF-8 texture path hint after validating local resources.
Lua preserves the sprite fallback if texture import or hint validation fails.

All ten firearm profiles can now use a hidden stable firing reference and a
separate animated visual mesh. The shot impulse rises from 1.1 to 2.8, retaining
the five-unit accumulation cap and smooth recovery. Projectile rotation and
spread remain unchanged. Recoil is triggered only by successful intercepted
projectile spawns; beam/hitscan paths bypassing that helper remain unverified.

Confirmed spawns request right-controller vibration on the engine tick:
40 ms, 90 Hz, amplitude 0.65, at most 20 pulses per second. Pellet/burst events
are coalesced. Selection feedback remains unchanged. `recoil_enabled=0` also
disables these firing pulses. Actual PS VR2 Sense strength requires VR testing.

Offline validation includes Python/Lua regressions, MSVC x64 `/W4 /WX` native
bridge tests/builds, source/binary hash checks and isolated deployment tests.
`runtimeVerified` and `verifiedInGame` remain false. No live profile deployment,
game launch, injection or publication is part of this revision.

Headset checks: sword texture/teeth, every weapon's feedback and muzzle alignment,
rapid fire, empty magazine, weapon switching, menu/off restoration and Sense intensity.
