# Boltgun VR

Mod de UEVR para Boltgun, desarrollado con PS VR2 Sense: controles adaptados, rueda
de armas, diez armas 3D opcionales, espada sierra izquierda y ajuste del Codex.
Una vez instalado, abre Boltgun e inyecta UEVR normalmente; no necesitas un lanzador.

La revisión 12 necesita comprobar sus últimos ajustes en visor. Las pruebas verifican
lógica y contratos, no la alineación real de todas las armas. No hay versión pública
todavía; las DLL se compilan localmente. El instalador base exige configuraciones
reconocidas y aún no es un instalador general para cualquier perfil nuevo.
